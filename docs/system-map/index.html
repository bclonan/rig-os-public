    How to read this map

    The map traces the current rig-os checkout. Click a box to read its responsibility, boundaries, relationships and exact source lines. Choose a journey to see its steps in order.

    The two model systems are different. Selected Ollama, Codex CLI or Claude CLI models supply proposals and artifact content. External clients require explicit consent; fallback or ensemble still returns only a proposal. The owned PyTorch/ONNX controller selects bounded skills after explicit qualification and activation. Neither can grant itself permission.

    A task is work with a contract. A run is its durable execution record. An HTTP request is an API call. These are not chats or projects.

    Implementation and test evidence are different. Native Mac execution and physical mixed-DPI qualification remain unresolved. General desktop learning is not established by the controlled browser experiments.

    This documentation does not call the runtime, read its token or operate your desktop. Source excerpts are build-time snapshots. No external scripts, fonts or services are needed.

    Mouse wheel and touch pinch zoom the map. Drag its background to move around. Use the zoom buttons and List view if you prefer reading without dragging. Escape closes a code dialog.
