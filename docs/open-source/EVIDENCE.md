# Evidence in the public repository

The public repository includes the complete maintained implementation, tests, setup scripts, native worker source, SDKs, controlled fixture data, owned model files and current documentation. It starts with a new Git history.

Private runtime stores, service tokens, evaluator signing keys, personal app captures, raw desktop inspections, local command logs, installed dependencies and downloaded provider weights are excluded. Historical review workspaces and copies of earlier documentation are excluded too. None is needed to run the source or open the architecture map.

Some operating and architecture documents describe earlier checks that used those private records. Links to omitted records point here in the public edition. Those descriptions remain historical results. The public edition does not claim readers can independently reconstruct a private native desktop session from the published summaries.

Controlled model weights and image files retain their exact bytes. Public metadata derivatives remove personal source paths and machine IDs, then update dependent hashes. The [portable evidence record](PORTABLE_EVIDENCE.md) explains the boundary. A public training-origin record is provenance, not an evaluator secret. Do not edit sealed data to change its results or label old checks as new executions.

[VERIFICATION.md](VERIFICATION.md) records the new checks. The export manifest records which files were copied, changed for publication or omitted. The map has its own static source and documentation check. It does not execute the assistant or qualify a model.
