# Reporting security issues

Send vulnerabilities and sensitive reports to [clonanxyz@gmail.com](mailto:clonanxyz@gmail.com). Include the affected version, a reproduction using disposable data, and the observed result. Do not post live tokens, keys, private screenshots or runtime databases in a public issue.

The project is an experimental local desktop assistant. Its [runtime security document](computer-use-runtime/SECURITY.md) explains authentication, local model access, permissions and execution checks. The [publication audit](docs/open-source/SECURITY_AUDIT.md) records the privacy review for this public source release.
