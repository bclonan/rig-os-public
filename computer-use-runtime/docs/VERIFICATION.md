## Reproduction

Use `npm run check` for ordinary integration checks, `python scripts/verify.py` for recorded quality and `python scripts/clean-install.py` for isolated source installation. On Unix use `python3` unless a Python environment is active. Use disposable stores and review native ownership rules before any live desktop evaluation. [RUNNING.md](RUNNING.md) covers setup, shutdown, backup, restart, tokens and local qualification.

`python scripts/completion.py` enforces the frozen repository contract. `--render` still validates and writes its reports, but suppresses the nonzero exit for acceptance issues. The [checklist](COMPLETION_CHECKLIST.md) and [evidence index](COMPLETION_EVIDENCE.json) retain historical acceptance rows; they are not a fresh repaired-source aggregate. Ordinary operation does not require private local acceptance records.

`npm run train` writes new candidates without activating them. `npm run verify:audit` checks the existing sealed audit without rerunning episodes. Evaluate refuses to overwrite a sealed final. Use a fresh namespace for local requalification, preserve its key and inputs, then explicitly install and activate only after passing qualification. Preserve all failed attempts. Never delete a live Store lock, tune against protected final outcomes or infer input cleanup from forced process exit.
